# 11. Risks and Technical Debt

## 11.1 Open Gaps in the Content Format

Things the reference story needs but the package format has no field for. These are content the LLM
or the UI currently has to improvise, not bugs in the packages. Closing one includes filling the gap
in `stories/lucys-portmonnaie/` and removing its entry here.

| Gap                                                | Effect today                                                                                                                                                                                                                                                                                                                                                                                                |
| -------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Only the group scene can set an arbitrary flag** | A scene's settable-flag surface is its `exitConditions` (plus, for a group scene, its `outcomes[].condition`s), because those are the only `flag:` refs the director is shown. A story that wants a flag set mid-scene without ending it — a wrong accusation in a one-to-one chat, say — has no field for that; the reference story therefore models its false accusation only in the group confrontation. |
| **World files the format never grew**              | The original concept sketched `world/timeline.json`, `world/locations.json` and `world/glossary.json` alongside clues/facts/secrets, plus a `rules/runtime.json`. None has a schema; the validator recognises only `clues.json`, `facts.json` and `secrets.json`, and a world file with any other name validates vacuously. Timeline, place and glossary knowledge therefore has to be smuggled into facts. |
| **Prompt and safety rule files**                   | The concept paper sketched `rules/prompts.json` (per-character / per-scene prompt templates) and `rules/safety.json` (tone and genre guardrails, canon protection). Neither has a schema; persona prompting is entirely app-side today.                                                                                                                                                                     |
| **Package update strategy**                        | There is no defined behaviour for updating an already-installed package, or for a character whose identity is published in a newer version. A savegame's relationship to a package version is likewise undefined beyond the semver convention that a major bump may invalidate it.                                                                                                                          |
| **Character version conflicts**                    | If two packages ship the same character UUID with different identity content, the library keeps whichever it resolved first. No conflict surface, no merge strategy.                                                                                                                                                                                                                                        |
| **Clue-conflict presentation**                     | The engine detects contradicting claims and the UI shows a contradiction panel, but there is no authored guidance for how a story wants a conflict presented or resolved.                                                                                                                                                                                                                                   |

## 11.2 Technical Risks

| Risk                                        | Impact                                                                                                                                                                                                                        | Mitigation / status                                                                                                                                                                                                                  |
| ------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Inference runs on the main thread**       | Long decode loops block JavaScript; anything JS-driven freezes during a reply.                                                                                                                                                | Typing and spinner animations are CSS-only. There is no worker variant of the WebLLM path today.                                                                                                                                     |
| **Two decode passes per player turn**       | Latency roughly doubles versus a single reply, on the slowest devices noticeably.                                                                                                                                             | Accepted: the director is what makes the story advance at all. The director session is minimal and short-lived.                                                                                                                      |
| **No GPU in CI or the dev sandbox**         | Real inference is never exercised automatically; a provider regression can pass CI.                                                                                                                                           | The adapter is tested against a fake; real turns are verified by hand through `/dev/llm` and `/dev/story`.                                                                                                                           |
| **No Cache Storage polyfill in Node**       | `blob-store.ts` and everything downstream is only ever exercised in a real browser.                                                                                                                                           | `/dev/import` drives the real path by hand; `fake-indexeddb` covers the IndexedDB half.                                                                                                                                              |
| **Small-model fragility**                   | A 3B model breaks character, ignores canon or emits unparseable director answers.                                                                                                                                             | Facts and secrets carry full sentences; per-scene relevance lists narrow the prompt; the director parser normalises two known near-miss shapes and allowlists everything else.                                                       |
| **Device exclusion**                        | Devices without WebGPU and without a built-in model can only play via an inference endpoint they must supply themselves.                                                                                                      | Accepted trade of [ADR 7](./09-architecture-decisions.md#adr-7-one-local-model-tier), mitigated by [ADR 15](./09-architecture-decisions.md#adr-15-a-player-configured-openai-compatible-endpoint-preferred-over-the-local-backends). |
| **No build-level guard against cloud SDKs** | "No cloud calls" is a rule nothing enforces: an earlier stub alias in `vite.config.ts` is gone, and `no-backend-leakage.spec.ts` guards `@mlc-ai/web-llm` only. A convenient dependency could ship an unnoticed network path. | Currently review-only. Reinstating an alias stub or widening the boundary spec would close it — see [ADR 14](./09-architecture-decisions.md#adr-14-no-cloud-sdk-dependency).                                                         |
| **Endpoint API key in `localStorage`**      | A stored API key is readable by any script running on the origin. Many endpoints (a local Ollama, llama.cpp) need no key at all.                                                                                              | Accepted: there is no server to hold it, the key is the player's own, and the feature is opt-in and clearly labelled.                                                                                                                |
| **Browser storage eviction**                | A browser may evict IndexedDB or Cache Storage, taking savegames or an installed package with it.                                                                                                                             | Not currently mitigated. Storage persistence has not been requested and there is no export/backup path.                                                                                                                              |
| **Thin coverage of the runes singletons**   | Reactive wiring bugs are invisible to the Node suite.                                                                                                                                                                         | Logic is pushed into pure modules that _are_ covered; the wrappers stay deliberately thin.                                                                                                                                           |

## 11.3 Product-Level Debt

- **The Authoring Studio does not exist.** Every package today is hand-authored JSON. The format was
  designed for a tool that has not been built, so ergonomics gaps in the format are currently
  invisible.
- **German only.** The i18n plumbing is in place and the dictionary is complete, but there is no
  second language, and no story package in another language has been exercised end to end.
- **One story.** The format's cross-story claims — character reuse by UUID, library deduplication —
  are validated by test fixtures, not by two real, independently released stories.
